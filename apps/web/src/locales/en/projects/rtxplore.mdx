# What I Built

I designed and implemented a small graphics engine that mixes **rasterization** and **ray tracing** under a single architecture: one scene, two complete pipelines, shared resource management, and comparable visual stages.

The key focus areas:

- Procedural terrain and water generation
- Texture and model tooling
- CPU - GPU synchronization
- TLAS/BLAS build
- Effect parity (visual results are directly comparable between rendering techniques).

Key takeaways:

- rasterization wins for throughput and predictable cost; great for live interaction and broad hardware.
- RT wins for correctness of reflection/refraction at grazing angles, edge cases, and multi-bounce paths.
- My engine lets you toggle the pipeline while keeping the same scene and materials, so differences are visible—not theoretical.

# Technical Highlights

## Procedural Terrain (Height Map)

<ProjectImage
  src={`${imagesPath}/TerrainHeightMap.png`}
  alt="Height map"
  caption="Fractal fBm (Simplex) height generation → chunked mesh + AABB per chunk for frustum culling."
/>

What I implemented:

- fBm(Simplex) height synthesis wrapped in a reusable “heightFunction(x, z)”.
- Chunked surface builder that emits submeshes, indices, and per-chunk AABBs.
- Culling in world space (inverse-view frustum + object transforms) to keep only visible chunks on the GPU.

## Water: Small vs Large Waves

What I implemented:

- A parametric Gerstner wrapper that outputs displaced position and TBN per-vertex (used in both pipelines).
- Unified material model so water shading is comparable between raster and RT.

## Shadows

<ProjectImage
  src={`${imagesPath}/ShadowMap.png`}
  alt="Shadow map"
  caption="Depth-only pass, PCF filtering; consistent biasing tuned for mountainous terrain."
/>

What I implemented:

- Depth atlas + PCF sampling tuned for terrain scale and water contact.
- Ray-based shadow checks for RT path when enabled (free of biasing artifacts).

## Ray–Surface Intersection (Procedural)

<ProjectImage
  src={`${imagesPath}/IntersectionShader2.png`}

What I implemented:

- TLAS/BLAS build + shader tables; custom Intersection Shader for procedurally displaced water within AABBs.
- Miss shader sampling the rotating skybox; recursive rays for reflection/refraction.
